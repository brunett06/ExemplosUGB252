# 🧮 Conceitos Básicos de C# com Testes

Exercícios de **fundamentos de C#** da graduação em Sistemas de Informação (UGB, 2025/2), acompanhados de **testes unitários**.

## Exercícios
- **SomaDoisNumeros:** soma de dois números inteiros
- **CalculaAumento:** cálculo de aumento percentual sobre um valor
- **MetrosMilimetros:** conversão de metros para milímetros

## Estrutura
```
ConceitosBasicos/        # exercícios (pasta uteis/)
TesteConceitosBasicos/   # testes unitários (MSTest)
```

## Como rodar
- Aplicação: `dotnet run --project ConceitosBasicos`
- Testes: `dotnet test`
